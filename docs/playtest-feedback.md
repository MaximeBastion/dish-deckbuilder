# Playtest Feedback And Ideas

This document tracks playtest notes, direction changes, and loose ideas. A
checked box means the note is already reflected in the current rules or card
data, not that the design is final.

## Playtest 1

- [x] Add more Peeling. The first test did not create enough deck-thinning or
  destructive deck-manipulation moments.
- [x] Add more interaction. Short, silly games can tolerate brutal interaction,
  especially if effects create memorable stories instead of only negating meals.
- [x] Make interaction scale for multiplayer. Prefer effects like `each
  opponent`, visible boards, and comparison hooks that still work above 2
  players.
- [x] Build out multiple Status cards instead of relying only on `Distraction`.
- [x] Create a Status-card archetype. Include cards that reward stuffing decks
  with Statuses, including a possible alternate-win quest.
- [x] Update `Clean Station` so it Peels itself once there are no starter cards
  left to Peel.
- [x] Add more market rotation so the shop does not get stuck on cards nobody
  wants.
- [x] Push weak 2-cost dishes above starter-card quality. Cheap market dishes
  should feel like real purchases, not slightly upgraded `Simple Soup`.
- [x] Add more Time generation on dishes, actions, and/or meal assembly.
- [x] Add one-copy, high-impact faction passives. These should be strong,
  silly, and direction-setting.
- [x] Add common passives with both upside and downside. These should reward a
  build direction without being automatic purchases for every deck.
- [x] Add an extreme Japanese Peel card where players Peel from the top of their
  decks, with room for Peel-related effects to trigger.
- [x] Add more card draw and card selection.
- [x] Generate missing artwork for the new cards.

## Playtest 2

- [x] Add a one-card arsenal-style system called the `Fridge` / `Frigo`.
- [x] Keep played and presented cards on each player's board until the beginning
  of that player's next turn.
- [x] Start each turn by discarding the active player's board, then drawing the
  new hand.
- [x] Use persistent boards so players can compare dishes against other players'
  most recent meals.
- [x] Make draw effects during opponents' turns matter. Cards drawn outside your
  turn stay in hand, and you still draw 5 at the start of your next turn.
- [x] Restrict the post-judging phase to learning cards with remaining Time.
- [x] Let top-N deck selection effects reshuffle discard first when the deck is
  too small.
- [x] Replace awkward top-deck Peel wording with the `Scorch` keyword.

## Card Review Notes

- [x] Rewrite `Knife Skills` without the unexplained `Upgrade` shorthand.
- [x] Make `Clean Station` a clearer modal choice.
- [x] Change `Taste Test` so it can only Peel the card it just discarded.
- [ ] Revisit whether `Heckle` should hit for 2 Statuses in 1v1 after more
  1v1 tests.
- [ ] Revisit whether `Mine Is Better` should compare from hand or from board
  now that boards persist.
- [x] Increase `Order` to cost 3.
- [x] Change `Omakase` so it finds a Dish for hand now and allows presenting it
  later this turn.
- [x] Change `Wasabi Attack` and `You Call That Sushi?` to use `Scorch`.
- [x] Change `Mamma Mia!` so the found Dish can be presented this turn and the
  judge condition grants Time instead.
- [x] Reduce `Secondo` to cost 3.
- [x] Buff `Doomscroll The Menu` while keeping the self-Status drawback.
- [x] Move `Chef's Kiss` Taste tracking from hand to a Dish on board.
- [x] Increase `5 Stars` to +4 Favor.

## General Ideas

- [x] Add a small spicy-meal test package. These dishes have very high Taste for
  their cost, but make you Peel cards from the top of your deck.
- [x] Name the spicy self-Peel action `Scorch`.
- [ ] Decide whether spicy meals should become a full win-fast or lose-fast
  archetype after testing the first package.
- [x] Add flexible dishes. Their Taste is inefficient for the cost, but they can
  be presented as any course slot.
- [x] Add first Fridge-support cards beyond the base Fridge rule.
- [x] Fold hand-made website-only cards from the export back into the repo
  source data and next playtest export.
- [ ] Revisit deck size and unique-card count after more testing. The current
  larger pool gives stronger variety, but it may need pruning once archetypes
  are clearer.
- [x] Decide that `Fridge` cards are face down and each Fridge holds at most 1
  card.
- [x] Use a different scoring wrapper for multiplayer: 1v1 keeps the judge
  track, while 3+ players use a personal Favor threshold.
- [ ] Decide whether the personal Favor threshold should also replace the 1v1
  judge track.
